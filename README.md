# 🚀 JC Agency

Landing page moderna e responsiva desenvolvida com Bootstrap 4, simulando o site institucional de uma agência digital.

---

## 📌 Sobre o projeto

O projeto **JC Agency** foi desenvolvido com foco em aprendizado e prática de desenvolvimento front-end moderno.

A aplicação simula uma agência digital profissional, apresentando uma interface moderna, responsiva e com diversos efeitos visuais e interativos.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 4
* JavaScript
* jQuery
* Font Awesome
* ProgressBar.js
* Parallax.js

---

## ✨ Funcionalidades

✔️ Navbar responsiva
✔️ Carousel interativo
✔️ Scroll suave entre seções
✔️ Contadores animados
✔️ Efeito Parallax
✔️ Filtro dinâmico no portfólio
✔️ Sessão de equipe
✔️ Newsletter personalizada
✔️ Formulário de contato
✔️ Layout totalmente responsivo

---

## 📱 Responsividade

O projeto foi desenvolvido para diferentes dispositivos:

* 💻 Desktop
* 📱 Smartphones
* 📲 Tablets

## 🎯 Objetivo do projeto

Este projeto foi criado para praticar:

* Estruturação de páginas modernas
* Responsividade com Bootstrap
* Manipulação de elementos com JavaScript/jQuery
* Criação de interfaces profissionais
* Organização de código front-end
* Experiência do usuário (UI/UX)
